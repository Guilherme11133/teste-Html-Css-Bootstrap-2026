Minha Primeira página com HTML+Bootstrap

Bootstrap é um framework front-end de código aberto usado para criar interfaces de sites e aplicações web de forma rápida e responsiva. Ele fornece um conjunto de componentes prontos e estilos em CSS, além de recursos em JavaScript.

O que o Bootstrap oferece?

Sistema de grid (grades): facilita organizar o conteúdo da página em colunas que se adaptam a diferentes tamanhos de tela.
Componentes prontos: botões, menus de navegação, formulários, tabelas, cards, modais, alertas, entre outros.
Design responsivo: o layout se ajusta automaticamente para celulares, tablets e computadores.
Classes utilitárias: permitem alterar espaçamentos, cores, alinhamentos e tamanhos sem escrever muito CSS.
